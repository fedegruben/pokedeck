# PokeDeck

PokeDeck es un e-commerce de cartas de Pokémon TCG desarrollado como proyecto final del curso de React.

## Tecnologías utilizadas

- React
- JavaScript
- Vite
- CSS

## Instalación

Para instalar las dependencias del proyecto:

```bash
npm install
```

## Ejecución

Para iniciar la aplicación:

```bash
npm run dev
```
